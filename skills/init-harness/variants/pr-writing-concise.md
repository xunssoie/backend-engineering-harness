# PR 작성 규칙

리뷰어가 3분 안에 변경을 파악하게 쓴다.

## 제목

- 형식: `{type}: {설명}(#{이슈번호})`. 설명은 40자 이내 명사형
- 대상을 나열하지 말고 무엇을 해결했는지를 남긴다

## 본문

- `.github/PULL_REQUEST_TEMPLATE.md`의 섹션 구조를 따른다. 템플릿의 HTML 주석은 넣지 않는다
- 섹션마다 불릿 1~3개. 문장은 짧게, 존댓말
- 변경 이유와 리뷰어가 특히 봐야 할 곳을 쓴다. 변경 파일 목록은 쓰지 않는다
- 성능 개선이면 측정 기록의 전후 수치를 표 하나로 붙인다. 재지 않은 값은 추정하지 않는다
- 가운데점 대신 콤마, 긴 대시 대신 짧은 대시
- 마지막 섹션에 `- close #{이슈번호}`
